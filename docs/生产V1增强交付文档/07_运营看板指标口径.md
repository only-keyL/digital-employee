# 运营看板指标口径

本文记录阶段 5 `OperationDashboardService` 全部指标口径。实现文件：`app/services/operation_dashboard_service.py`、`app/repositories/operation_dashboard_repository.py`。

## 1. 今日提问数

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `create_time` |
| 计算公式 | `count(id) WHERE create_time >= 今日 00:00` |
| 空数据处理 | 返回 0 |
| 业务含义 | 当天活跃提问量 |

## 2. 总提问数

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `id` |
| 计算公式 | `count(id)` 全表 |
| 空数据处理 | 返回 0 |
| 业务含义 | 累计问答规模 |

## 3. 命中率

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `matched` |
| 计算公式 | `count(matched=1) / count(id)`，分母为 0 返回 0 |
| 空数据处理 | hit_rate = 0 |
| 业务含义 | 知识库覆盖程度 |

## 4. 未命中率

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `matched` |
| 计算公式 | `total - matched`，最小 0 |
| 空数据处理 | miss_count = 0 |
| 业务含义 | 需补充知识的缺口 |

## 5. 置信度分布

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `confidence_level` |
| 计算公式 | 分别 count high/medium/low/none |
| 空数据处理 | 各档默认 0 |
| 业务含义 | 回答可信程度结构 |

## 6. 平均耗时

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `latency_ms` |
| 计算公式 | `avg(latency_ms)`，跳过 NULL |
| 空数据处理 | 返回 None 或 0 |
| 业务含义 | 用户体验与性能 |

## 7. 有用 / 无用 / 补充反馈

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `feedback_log` |
| 统计字段 | `feedback_type` |
| 计算公式 | count useful / useless / supplement |
| 空数据处理 | 各类型 0 |
| 业务含义 | 用户满意度与纠错需求 |

## 8. 回答有效率

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `feedback_log` |
| 统计字段 | `feedback_type` |
| 计算公式 | `useful / (useful + useless)`，分母 0 返回 0 |
| 空数据处理 | effective_rate = 0 |
| 业务含义 | 有效反馈中的满意比例 |

## 9. 知识卡片状态

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `knowledge_card` |
| 统计字段 | `deleted`、`audit_status`、`need_review` |
| 计算公式 | total(deleted=0)；approved/pending/draft/rejected 分组；need_review=1 计数 |
| 空数据处理 | 各状态 0 |
| 业务含义 | 知识库治理进度 |

## 10. 待复核知识

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `knowledge_card` |
| 统计字段 | `need_review` |
| 计算公式 | `count(need_review=1 AND deleted=0)` |
| 空数据处理 | 0 |
| 业务含义 | 需人工关注的卡片数 |

## 11. 重复检测分布

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `knowledge_duplicate_check_log` |
| 统计字段 | `check_level` |
| 计算公式 | 近 N 天（默认 7）按 high_duplicate/suspected_duplicate/related/none 计数 |
| 空数据处理 | 各档 0 |
| 业务含义 | 知识重复治理情况 |

## 12. 重复预警数

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `knowledge_duplicate_check_log` |
| 统计字段 | `check_level` |
| 计算公式 | `high_duplicate + suspected_duplicate` |
| 空数据处理 | 0 |
| 业务含义 | 需关注的重复风险量 |

## 13. 高频未命中 Top10

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `unanswered_question` |
| 统计字段 | `frequency`、`question`、`last_seen_time`、`status` |
| 计算公式 | order by frequency desc limit 10 |
| 空数据处理 | 返回 [] |
| 业务含义 | 优先补知识的未命中问题 |

## 14. 高频系统/模块 Top10

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `system_name`、`module_name` |
| 计算公式 | group by system_name+module_name，近 N 天，count desc limit 10 |
| 空数据处理 | 返回 [] |
| 业务含义 | 业务热点领域 |

## 15. 最常被引用知识卡片 Top10

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `question_log` |
| 统计字段 | `primary_matched_card_id`、`primary_matched_card_title` |
| 计算公式 | 非空 card_id 分组 count desc limit 10 |
| 空数据处理 | 返回 [] |
| 业务含义 | 高价值知识卡片 |

## 16. 风险知识卡片 Top10

| 项 | 说明 |
| --- | --- |
| 数据来源表 | `knowledge_card` |
| 统计字段 | `need_review`、`useless_count`、`supplement_count`、`quality_score` |
| 计算公式 | order by need_review desc, useless_count desc, supplement_count desc, quality_score asc limit 10 |
| 空数据处理 | 返回 [] |
| 业务含义 | 需优先治理的低质量卡片 |
