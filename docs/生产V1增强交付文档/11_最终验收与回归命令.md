# 最终验收与回归命令

## 1. 完整验收命令（Windows PowerShell）

```powershell
cd F:\WorkSpace\digital-employee-assistant

git branch --show-current

.\.venv\Scripts\Activate.ps1

$env:PYTHONIOENCODING="utf-8"

python -m pip install -r requirements.txt

python -m compileall app scripts

python app/db/init_db.py

python scripts/prod/init_stage3_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_stage4_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_stage6_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_enhance_stage1_tables.py --env-file "docs/prod/.env"

python scripts/prod/check_enhance_stage1_logs.py --env-file "docs/prod/.env"
python scripts/prod/check_enhance_stage2_trusted_answer.py --env-file "docs/prod/.env"
python scripts/prod/check_enhance_stage3_duplicate_check.py --env-file "docs/prod/.env"
python scripts/prod/check_enhance_stage4_feedback_loop.py --env-file "docs/prod/.env"
python scripts/prod/check_enhance_stage5_operation_dashboard.py --env-file "docs/prod/.env"
python scripts/prod/check_enhance_stage6_context_memory.py --env-file "docs/prod/.env"

python scripts/prod/check_enhance_stage7_docs.py

python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env" --fast
```

## 2. 无 docs/prod/.env 时

将所有 `--env-file "docs/prod/.env"` 替换为 `--env-file ".env"`。

## 3. 各脚本检查内容

| 脚本 | 检查内容 | PASS 标准 |
| --- | --- | --- |
| check_enhance_stage1_logs.py | 表字段、索引、ORM | 全部 [PASS] |
| check_enhance_stage2_trusted_answer.py | 可信回答格式与落库 | 全部 [PASS] |
| check_enhance_stage3_duplicate_check.py | 重复检测与沉淀 | 全部 [PASS] |
| check_enhance_stage4_feedback_loop.py | 反馈闭环 | 全部 [PASS] |
| check_enhance_stage5_operation_dashboard.py | 运营看板指标 | 全部 [PASS] |
| check_enhance_stage6_context_memory.py | 追问与 Redis | 全部 [PASS] |
| check_enhance_stage7_docs.py | 交付文档齐全 | exit 0 |
| run_all_regression_checks.py --fast | 汇总回归 | [结果] 全部通过 |

## 4. FAIL 后排查

1. 看脚本输出的 `[FAIL] 失败项` 与 `失败原因`
2. 确认 MySQL 已启动、env-file 路径正确
3. Windows 设置 `PYTHONIOENCODING=utf-8`
4. 数据库脏数据：验收脚本通常自带清理；可手动查 `__stage*_` 标记数据
5. 文档 FAIL：检查 `docs/生产V1增强交付文档/` 文件是否齐全

## 5. 启动服务后人工抽检

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

- 运营看板：`http://127.0.0.1:8001/operation-dashboard`
- 问答：`POST http://127.0.0.1:8001/api/ask`
- 企微模拟：`POST http://127.0.0.1:8001/api/mock/wecom/message`

## 6. 一键 fast 回归

```powershell
python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env" --fast
```

包含：配置检查、Stage4～6 增强验收、Stage5 后台审核、Stage6 安全扫描、Stage7 文档检查、向量任务统计等。
