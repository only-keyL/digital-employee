# 数据流转与核心表说明

## 1. question_log

| 项 | 说明 |
| --- | --- |
| 用途 | 每次有效提问的完整记录 |
| 关键字段 | question_raw、rewritten_question、matched、confidence_level、primary_matched_card_*、used_context、context_source、latency_ms |
| 写入模块 | AskLogService、AskRunLogService |
| 读取模块 | 运营看板、反馈绑定、30 天常问模块、后台日志页 |
| 业务价值 | 问答效果复盘、可信回答追溯、上下文增强统计 |

## 2. feedback_log

| 项 | 说明 |
| --- | --- |
| 用途 | 用户有用/无用/补充反馈事件 |
| 关键字段 | feedback_type、question_log_id、knowledge_card_id、status、supplement_text |
| 写入模块 | FeedbackEvolutionService |
| 读取模块 | 运营看板、后台反馈页 |
| 业务价值 | 反馈闭环、回答有效率 |

## 3. knowledge_card

| 项 | 说明 |
| --- | --- |
| 用途 | 正式知识卡片 |
| 关键字段 | title、question、answer、audit_status、enabled、useful_count、useless_count、quality_score、need_review、vector_status |
| 写入模块 | KnowledgeService、沉淀 Graph、反馈计数更新 |
| 读取模块 | 检索、审核、看板、重复检测 |
| 业务价值 | 知识库核心资产 |

## 4. knowledge_card_revision

| 项 | 说明 |
| --- | --- |
| 用途 | 补充反馈生成的修订建议（不直接改正文） |
| 关键字段 | knowledge_card_id、revision_content、status、source_feedback_id |
| 写入模块 | FeedbackEvolutionService |
| 读取模块 | 后台（预留审核流） |
| 业务价值 | 知识进化建议池 |

## 5. knowledge_duplicate_check_log

| 项 | 说明 |
| --- | --- |
| 用途 | 重复检测记录 |
| 关键字段 | source_card_id、check_level、check_result、similarity_score |
| 写入模块 | DuplicateCheckService |
| 读取模块 | 运营看板、审核参考 |
| 业务价值 | 知识治理、重复预警 |

## 6. unanswered_question

| 项 | 说明 |
| --- | --- |
| 用途 | 未命中问题聚合 |
| 关键字段 | normalized_question、frequency、status、last_seen_time |
| 写入模块 | AskLogService、AskRunLogService |
| 读取模块 | 后台未命中页、运营看板 Top |
| 业务价值 | 驱动知识补全 |

## 7. ask_run

| 项 | 说明 |
| --- | --- |
| 用途 | AskGraphV2 运行主记录 |
| 关键字段 | run_id、question、status、confidence_level、latency_ms |
| 写入模块 | AskRunLogService |
| 读取模块 | RAG 调试、链路追踪 |
| 业务价值 | V2 问答运行审计 |

## 8. retrieval_log

| 项 | 说明 |
| --- | --- |
| 用途 | 单次 run 的检索 hit 明细 |
| 关键字段 | run_id、knowledge_id、score、rank |
| 写入模块 | AskRunLogService |
| 读取模块 | 调试、分析 |
| 业务价值 | 检索可解释性 |

## 9. llm_call_log

| 项 | 说明 |
| --- | --- |
| 用途 | LLM 调用记录 |
| 关键字段 | run_id、provider、model、status、latency_ms |
| 写入模块 | AskRunLogService |
| 读取模块 | 成本与稳定性分析 |
| 业务价值 | LLM 可观测 |

## 10. vector_sync_task

| 项 | 说明 |
| --- | --- |
| 用途 | 知识卡片向量同步任务 |
| 关键字段 | knowledge_card_id、status、error_message |
| 写入模块 | 向量同步服务 |
| 读取模块 | 运维检查脚本 |
| 业务价值 | Qdrant 与 MySQL 一致性 |

## 11. message_process_log

| 项 | 说明 |
| --- | --- |
| 用途 | 企微消息处理记录（幂等/审计） |
| 关键字段 | msg_id、process_status |
| 写入模块 | 企微回调/模拟链路 |
| 读取模块 | 幂等验收 |
| 业务价值 | 消息不重复处理 |

## 12. admin_operation_log

| 项 | 说明 |
| --- | --- |
| 用途 | 管理员操作审计 |
| 关键字段 | operation_type、target_id、operator |
| 写入模块 | 后台审核操作 |
| 读取模块 | 安全审计 |
| 业务价值 | 治理可追溯 |

## 13. 数据流总览

```text
提问 → question_log → 看板/反馈/30天记忆
反馈 → feedback_log → 卡片计数 → revision
沉淀 → knowledge_card → duplicate_log → 审核 → vector_sync → Qdrant
检索 ← Qdrant ← knowledge_card（approved+enabled）
```
