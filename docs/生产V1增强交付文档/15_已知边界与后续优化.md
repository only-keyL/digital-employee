## 2. 本阶段（阶段 7）边界

- **未新增任何业务功能**
- 仅新增文档、README 索引、文档检查脚本
- 未修改问答/反馈/重复检测/看板/追问主逻辑

## 3. 后续优化建议

### 3.1 接入与体验

1. 真实企微回调（加解密、被动回复）
2. 企微卡片按钮（有用/无用/补充）
3. 更自然的 LLM 追问改写（可选开关）

### 3.2 知识治理

4. revision 审核流与一键 merge
5. 知识冲突检测（同系统矛盾答案）
6. 重复卡片 merge 工具

### 3.3 性能与运维

7. 看板 Redis 缓存 / 定时预聚合
8. 自动化部署（Docker Compose / CI）
9. 灰度发布与配置中心

### 3.4 企业级能力

10. 多租户与细粒度权限
11. 更完整可观测性（指标、告警）
12. 读写分离与任务队列

### 3.5 文档知识库 RAG

13. 从文档自动生成候选 QA
14. 候选 QA 人工审核后转知识卡片
15. 文档命中统计与低满意度反推沉淀
16. 文档权限控制（按系统/模块/角色）
17. OCR 与表格结构化解析
18. rerank 提升混合检索精度
19. 文档版本 diff 与变更提醒

## 4. 技术债务提示

- AskGraph（V1）与 AskGraphV2 双链路并存，长期可统一
- 部分验收脚本依赖 Windows UTF-8 环境变量
- `docs/prod/.env` 仅本地使用，禁止提交

## 5. 收口结论

增强阶段 1～7 与文档知识库 RAG（阶段1～3）已完成：**可信回答 → 重复检测 → 反馈闭环 → 运营看板 → 多轮追问 → 文档交付 → 文档切片 RAG**。可在当前边界内对外演示与答辩；生产上线需完成企微真实接入与高可用改造。
