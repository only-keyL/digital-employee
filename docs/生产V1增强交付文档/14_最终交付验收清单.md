# 最终交付验收清单

## 1. 功能验收

- [ ] 检查项：`/api/ask` 可正常问答
- 验收方式：`POST /api/ask` 带 question
- 通过标准：返回 answer，非空问题写 question_log
- 失败处理：查 Qdrant/LLM 配置与日志

## 2. 接口验收

- [ ] 检查项：反馈、看板、企微模拟接口可用
- 验收方式：POST /api/feedback、GET /api/operation-dashboard/summary、POST /api/mock/wecom/message
- 通过标准：HTTP 200，结构符合 schema
- 失败处理：查 router 注册与 Service 异常

## 3. 页面验收

- [ ] 检查项：后台页面可访问
- 验收方式：浏览器打开 /operation-dashboard、/question-logs、/feedback
- 通过标准：页面渲染无 500
- 失败处理：查模板与数据库连接

## 4. 数据库验收

- [ ] 检查项：增强字段与表存在
- 验收方式：`python scripts/prod/check_enhance_stage1_logs.py`
- 通过标准：全部 PASS
- 失败处理：执行 init_enhance_stage1_tables.py

## 5. 向量库验收

- [ ] 检查项：Qdrant 检索可用
- 验收方式：完整回归含 check_rag_v2（非 fast）
- 通过标准：检索有 contexts
- 失败处理：检查 QDRANT_URL、collection、向量同步任务

## 6. Redis 验收

- [ ] 检查项：追问上下文可读写

## 7. LangSmith 验收

- 验收方式：`check_stage6_security.py`
