# 启动部署与环境变量说明

## 1. 本地启动步骤（通用）

1. 克隆仓库并进入目录
2. 创建虚拟环境并安装依赖
3. 配置 `.env`（可参考 `.env.example`，**勿提交 Git**）
4. 初始化 MySQL 表
5. 启动 uvicorn

## 2. Windows PowerShell 启动

```powershell
cd F:\WorkSpace\digital-employee-assistant
.\.venv\Scripts\Activate.ps1
$env:PYTHONIOENCODING="utf-8"
python -m pip install -r requirements.txt
python app/db/init_db.py
python scripts/prod/init_stage3_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_stage4_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_stage6_tables.py --env-file "docs/prod/.env"
python scripts/prod/init_enhance_stage1_tables.py --env-file "docs/prod/.env"
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

访问：`http://127.0.0.1:8001`

## 3. MySQL 初始化

- 需本地 MySQL 8.x 运行
- 环境变量：`MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`
- 基础表：`python app/db/init_db.py`
- 生产 V1 + 增强表：按顺序执行 `init_stage*.py`、`init_enhance_stage1_tables.py`

## 4. Redis 要求

- 多轮追问、沉淀 session 依赖 Redis
- 环境变量：`REDIS_URL`（例：`redis://127.0.0.1:6379/0`）
- Redis 不可用：追问降级为单轮；沉淀 session 会报错提示

## 5. Qdrant 要求

- RAG 检索依赖 Qdrant
- 环境变量：`QDRANT_URL`、`QDRANT_COLLECTION` 等
- 完整 RAG 回归需 Qdrant 可用；`--fast` 模式可跳过

## 6. LangSmith 环境变量

```text
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_key
LANGSMITH_PROJECT=digital-employee-assistant
```

可选；未配置不影响本地启动。

## 7. DeepSeek / LLM 环境变量

```text
DEEPSEEK_API_KEY=your_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

问答生成依赖 LLM；检索验收可不依赖。

## 8. 端口说明

- 默认 `APP_PORT=8001`
- 启动命令：`--host 127.0.0.1 --port 8001`

## 9. 常见启动问题

| 问题 | 排查 |
| --- | --- |
| MySQL 连接失败 | 检查服务、账号密码、库是否创建 |
| 中文乱码 | 设置 `$env:PYTHONIOENCODING="utf-8"` |
| Qdrant 连接失败 | 检查 QDRANT_URL；fast 回归可跳过 |
| Redis 未配置 | 追问/沉淀受限；看板/反馈仍可用 |
| 端口占用 | 换端口或结束占用进程 |

## 10. PYTHONIOENCODING 说明

Windows 控制台默认 GBK，验收脚本输出中文可能乱码或异常。建议：

```powershell
$env:PYTHONIOENCODING="utf-8"
```

再执行验收与回归命令。

## 11. 环境文件位置

- 本地开发：项目根 `.env`
- 团队共享（不提交）：`docs/prod/.env`
- **禁止**将含真实 Key 的 `.env` 提交 Git
