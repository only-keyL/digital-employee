# 核心模块职责说明

## 1. 问答模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 接收用户问题，编排 RAG 检索与答案生成 |
| 核心文件 | `app/services/ask_service.py`、`app/agent/graph_runner.py`、`app/graphs/ask_graph_v2.py` |
| 输入 | `AskRequest`（question、user_id、group_id） |
| 输出 | `AskResponse`（answer、sources、confidence_level） |
| 关键数据表 | `question_log`、`ask_run`、`retrieval_log`、`llm_call_log` |
| 不负责 | 反馈处理、知识审核、看板统计 |

## 2. 可信回答模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 按置信度包装答案、展示来源、决定 answer_status |
| 核心文件 | `app/services/trusted_answer_service.py` |
| 输入 | raw_answer、confidence_level、primary_source |
| 输出 | 带来源说明的可信答案、log_patch 字段 |
| 关键数据表 | `question_log`（confidence_level、primary_matched_card_*） |
| 不负责 | 向量检索、LLM 调用 |

## 3. 知识卡片模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 知识 CRUD、审核状态、启用/禁用 |
| 核心文件 | `app/services/knowledge_service.py`、`app/repositories/knowledge_repository.py` |
| 输入 | 卡片内容、审核操作 |
| 输出 | `knowledge_card` 记录 |
| 关键数据表 | `knowledge_card` |
| 不负责 | 向量写入（由 vector_sync 任务负责） |

## 4. 知识重复检测模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 新建/沉淀卡片时检测与库内卡片相似度 |
| 核心文件 | `app/services/duplicate_check_service.py` |
| 输入 | 卡片对象或待沉淀文本 |
| 输出 | check_level、check_result、写入 duplicate_check_log |
| 关键数据表 | `knowledge_duplicate_check_log` |
| 不负责 | 自动合并/删除重复卡片 |

## 5. 反馈闭环模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 解析有用/无用/补充，更新质量计数，生成 revision |
| 核心文件 | `app/services/feedback_evolution_service.py` |
| 输入 | 反馈文本或 API 请求 |
| 输出 | feedback_log、卡片计数、knowledge_card_revision |
| 关键数据表 | `feedback_log`、`knowledge_card_revision` |
| 不负责 | 直接修改正式知识卡片正文 |

## 6. 运营看板模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 只读聚合问答、反馈、知识、重复检测指标 |
| 核心文件 | `app/services/operation_dashboard_service.py`、`app/repositories/operation_dashboard_repository.py` |
| 输入 | days、limit 查询参数 |
| 输出 | summary/tops JSON、Jinja2 页面 |
| 关键数据表 | `question_log`、`feedback_log`、`knowledge_card`、`knowledge_duplicate_check_log`、`unanswered_question` |
| 不负责 | 修改业务数据 |

## 7. 多轮追问模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 识别追问、规则改写、Redis 上下文读写 |
| 核心文件 | `app/services/context_enhance_service.py`、`app/services/conversation_context_service.py` |
| 输入 | 原始问题、user_id、group_id |
| 输出 | rewritten_question、used_context、context_source |
| 关键数据表 | `question_log`（读写上下文字段）；Redis 短期缓存 |
| 不负责 | LLM 改写、长期个人画像 |

## 8. 企微模拟入口模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 模拟企微消息，分发指令/问答/沉淀/反馈 |
| 核心文件 | `app/wecom/command_router.py`、`app/routers/mock_wecom_router.py` |
| 输入 | `WeComMessage` |
| 输出 | `MockWeComResponse` |
| 关键数据表 | 同问答 + 沉淀链路 |
| 不负责 | 真实企微加解密回调 |

## 9. 后台审核模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | pending 卡片 approve/reject、风险拦截 |
| 核心文件 | `app/routers/admin_review_router.py`、`app/services/knowledge_service.py` |
| 输入 | 审核请求 |
| 输出 | audit_status 变更、向量同步触发 |
| 关键数据表 | `knowledge_card`、`admin_operation_log` |
| 不负责 | 自动审核 revision |

## 10. 向量同步模块

| 项 | 说明 |
| --- | --- |
| 模块职责 | 审核通过后写入 Qdrant |
| 核心文件 | `app/services/vector_sync_service.py`（或等价任务服务） |
| 输入 | knowledge_card_id |
| 输出 | vector_sync_task、vector_status |
| 关键数据表 | `vector_sync_task`、`knowledge_card.vector_*` |
| 不负责 | 检索逻辑本身 |
