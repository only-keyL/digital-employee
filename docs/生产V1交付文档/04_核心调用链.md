# 核心调用链

## 1. FastAPI 启动调用链

```text
uvicorn app.main:app
  ↓
create_app()
  ↓
run_runtime_check(settings)
  ↓ validate_settings + collect_startup_issues
  ↓ prod 有 error → RuntimeConfigError 阻止启动
  ↓
挂载 /static、注册各 router
  ↓
app 就绪
```

## 2. GET /api/health

```text
GET /api/health
  ↓
api_router
  ↓
返回 status / module / env（不查外部依赖）
```

## 3. GET /api/infra/health

```text
GET /api/infra/health?deep=false
  ↓
infra_router
  ↓
InfraHealthService.check_all()
  ↓
shallow：配置探测；deep=true：真实调用 Redis/Qdrant/LLM 等
  ↓
返回分项状态 JSON
```

## 4. POST /api/mock/wecom/message 普通问题

```text
POST /api/mock/wecom/message
  ↓
mock_wecom_router
  ↓
MessageIdempotencyService.begin_process
  ↓ duplicate_success → 直接返回
  ↓
CommandRouter.route
  ↓
CommandDetector → NORMAL_QUESTION
  ↓
AskGraphV2Runner.run
  ↓
mark_success → 返回 MockWeComResponse
```

## 5. POST /api/mock/wecom/message 沉淀指令

```text
POST /api/mock/wecom/message  content=【沉淀】
  ↓
MessageIdempotencyService
  ↓
CommandRouter → DEPOSIT_START
  ↓
DepositSessionService.create_session (Redis)
  ↓
返回 session_active=true
```

## 6. POST /api/mock/wecom/message 知识投稿

```text
POST /api/mock/wecom/message  content=结构化卡片
  ↓
MessageIdempotencyService
  ↓
CommandRouter → KNOWLEDGE_SUBMIT
  ↓
KnowledgeDepositGraphRunner.run
  ↓
写 knowledge_contribution / knowledge_card(pending)
  ↓
mark_success → 返回 contribution_id / knowledge_card_id
```

## 7. POST /api/ask-v2

```text
POST /api/ask-v2
  ↓
ask_v2_router
  ↓
AskGraphV2Runner.run
  ↓
Embedding → Qdrant → DeepSeek（或低置信度降级）
  ↓
写 ask_run / retrieval_log / llm_call_log
  ↓
AskV2Response
```

## 8. vector sync worker

```text
python scripts/prod/run_vector_sync_worker.py
  ↓
Stage3VectorSyncService.process_pending
  ↓
读取 vector_sync_task status=pending
  ↓
build_vector_text + Embedding → Qdrant upsert
  ↓
build_qdrant_payload（摘要字段）
  ↓
task.status=success，knowledge_card.vector_status=synced
```

## 9. 后台审核通过

```text
POST /api/admin/knowledge/{id}/approve
  ↓
require_admin_auth
  ↓
AdminReviewService.approve_knowledge
  ↓
audit_status=approved, enabled=1, vector_status=pending
  ↓
Stage3VectorSyncService.enqueue_for_card
  ↓
AdminOperationLogService.write_log
  ↓
repo.save()
```

## 10. 后台审核拒绝

```text
POST /api/admin/knowledge/{id}/reject
  ↓
require_admin_auth
  ↓
AdminReviewService.reject_knowledge（必须 audit_remark）
  ↓
audit_status=rejected，不创建 vector_sync_task
  ↓
write_log + save
```

## 11. 操作审计

```text
GET /api/admin/operation-logs
  ↓
require_admin_auth
  ↓
AdminOperationLogService.list_logs
  ↓
脱敏 before/after 快照返回
```

## 12. 一键回归

```text
python scripts/prod/run_all_regression_checks.py
  ↓
依次 subprocess 执行 check_prod_config / check_ai_infra / ...
  ↓
汇总 PASS/FAIL/SKIP 表
  ↓
任一 FAIL → exit 1
```
