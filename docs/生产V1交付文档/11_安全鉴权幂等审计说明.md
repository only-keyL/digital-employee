# 安全鉴权幂等审计说明

## 1. 配置安全

- `app/core/env_validator.py` 按 APP_ENV 分级校验
- prod 禁止 mock LLM、local Qdrant、root 数据库账号
- prod 必须：`ADMIN_AUTH_ENABLED=true`、`ADMIN_TOKEN`、`MESSAGE_DEDUP_ENABLED=true`

## 2. docs/prod/.env 保护

- 路径：`docs/prod/.env`（本地真实配置）
- **不得提交 Git**（`.gitignore` 已配置）
- 启动检查与安全扫描会检测 Git 跟踪状态

## 3. Admin Token 鉴权

| 配置项 | 说明 |
| --- | --- |
| `ADMIN_AUTH_ENABLED` | dev 可 false，prod 必须 true |
| `ADMIN_TOKEN` | 后台 Token，禁止打印明文 |
| `ADMIN_TOKEN_HEADER` | 默认 `X-Admin-Token` |

保护范围：`/api/admin/*`、`/admin/*`

不保护：`/api/health`、`/api/mock/wecom/message`、`/api/ask-v2`、原 `/api/ask`

## 4. 为什么当前不是完整 RBAC

本阶段目标是**内网测试管理保护**，Header Token 实现简单、适合演示与验收。正式生产应接 SSO / RBAC，支持用户、角色、操作粒度权限。

## 5. message_id 幂等

- 表：`message_process_log`
- 键：`source + message_id`
- 状态：processing → success / failed
- 重复 success 返回历史脱敏响应
- 同 id 不同 content → `duplicate_conflict`
- failed 允许重试

## 6. 审计日志

- 表：`admin_operation_log`
- 覆盖：approve / reject / mark-reviewed / ignore_duplicate / keep_blocked
- before/after 仅关键字段摘要
- 与审核主操作同一事务 `save()`

## 7. LangSmith 脱敏

```text
LANGSMITH_HIDE_INPUTS=true
LANGSMITH_HIDE_OUTPUTS=true
```

不上传完整问题、答案、知识正文。

## 8. Qdrant payload 控制

`build_qdrant_payload` 仅保存 `question_preview` 等摘要，**不保存完整答案正文**。向量文本 `build_vector_text` 可含正文用于 embedding，与 payload 分离。

## 9. 安全扫描

```powershell
python scripts/prod/check_stage6_security.py --env-file "docs/prod/.env"
```

检查：Git 跟踪、example 文件、代码库疑似密钥；跳过 `docs/prod` 目录内容扫描。

## 10. 当前风险与后续建议

| 风险 | 建议 |
| --- | --- |
| Header Token 泄露 | 轮换 Token；接 RBAC |
| processing 卡住 | 监控 + 后续超时恢复 |
| 扫描误报 | 结合 pre-commit + 人工复核 |
| 审计失败未回滚 | 生产化压测并加强事务策略 |
