# 运维与回归验收指南

## 1. 一键回归命令

```powershell
# 快速回归（跳过 LLM/RAG 等耗时真实调用）
python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env" --fast

# 完整回归
python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env"
```

## 2. fast / full 区别

| 模式 | 说明 |
| --- | --- |
| `--fast` | 跳过 AI 基础设施、RAG、模拟企微沉淀、审核流、Stage5/6 补充、幂等等耗时项 |
| full | 执行全部 11 项检查，含真实外部调用 |

## 7. 常见失败原因

| 现象 | 可能原因 |
| --- | --- |
| 配置检查失败 | prod 缺 ADMIN_TOKEN、MESSAGE_DEDUP 等 |
| AI 基础设施失败 | Redis/Qdrant/Key 未配置或网络不通 |
| RAG 低置信度 | 知识未审核同步到 Qdrant |
| 沉淀失败 | Redis 未启动 |
| 后台 401 | 鉴权开启但缺 Token |
| 安全扫描失败 | 代码库疑似密钥或 prod/.env 被 Git 跟踪 |

## 8. 回归失败处理

1. 查看脚本输出的 `[FAIL]` 摘要
2. 单独重跑失败项脚本
3. 修复配置或依赖后重跑一键回归
4. 任一关键项失败，退出码非 0，**不得视为验收通过**
