# 文档总览

## 1. 文档用途

本目录为「数字员工助手 · 二期优化」**生产 V1 交付文档**，用于：

- 项目交付与验收
- 本地/测试环境部署与运维
- 业务演示与讲解
- 开发复盘与面试表达

文档基于阶段 1～7 实际代码整理，配置示例均使用占位符，**不包含真实密钥**。

## 2. 文档适用对象

| 对象 | 说明 |
| --- | --- |
| 业务人员 | 了解业务流程、演示话术 |
| 开发人员 | 架构、调用链、接口、数据流 |
| 运维人员 | 启动、部署、回归、安全 |
| 面试/复盘 | 项目亮点与追问回答 |
