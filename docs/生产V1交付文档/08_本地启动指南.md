# 本地启动指南

## 1. 环境要求

- Python 3.10 或 3.11
- MySQL 8.x（已建库）
- Redis（阶段 4 沉淀 Session 需要）
- 可选：Qdrant local 或 remote、DeepSeek API Key

## 2. Python 虚拟环境

```powershell
cd F:\WorkSpace\digital-employee-assistant
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

## 3. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

## 4. 配置 .env

```powershell
Copy-Item .env.example .env
```

按需修改（占位符示例）：

```text
APP_ENV=dev
APP_PORT=8001
MYSQL_HOST=127.0.0.1
MYSQL_USER=your_user
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=digital_employee
REDIS_URL=redis://127.0.0.1:6379/0
LLM_API_KEY=your_llm_api_key
QDRANT_MODE=local
ADMIN_AUTH_ENABLED=false
```

本地真实配置可放在 `docs/prod/.env`，**不要提交 Git**。

## 5. 初始化数据库

```powershell
python app/db/init_db.py
python scripts/prod/init_stage3_tables.py --env-file ".env"
python scripts/prod/init_stage4_tables.py --env-file ".env"
python scripts/prod/init_stage6_tables.py --env-file ".env"
```

## 6. 配置检查

```powershell
python scripts/prod/check_prod_config.py --env dev --env-file ".env"
```

## 7. 启动服务

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

端口需与 `APP_PORT` 一致。

## 9. 常见问题

| 问题 | 处理 |
| --- | --- |
| 端口占用 | 临时换端口或结束占用进程 |
| MySQL 连接失败 | 检查服务、账号、库名 |
| Redis 不可用 | 沉淀【沉淀】会失败，需启动 Redis |
| prod 配置阻止启动 | dev 用 `APP_ENV=dev` |
| 后台 401 | 开启鉴权时需加 `X-Admin-Token` 请求头 |
