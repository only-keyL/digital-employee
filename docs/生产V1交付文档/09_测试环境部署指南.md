# 测试环境部署指南

> 本文描述测试环境部署步骤，**不写真实服务器 IP、域名、密钥**。

## 1. 部署前准备

- [ ] 确认阶段 1～6 代码已提交或通过回归
- [ ] 准备测试 MySQL 库（独立库名，勿用生产库名）
- [ ] 准备 Redis、Qdrant remote、DeepSeek Key、LangSmith 项目
- [ ] 复制 `.env.test.example` 为测试 env 文件（勿直接使用 `.env.prod.example` 上线）

## 2. 测试环境配置项

```text
APP_ENV=test
ADMIN_AUTH_ENABLED=true
ADMIN_TOKEN=your_strong_test_admin_token
MESSAGE_DEDUP_ENABLED=true
MESSAGE_DEDUP_TTL_SECONDS=86400
QDRANT_MODE=remote
QDRANT_URL=https://your-qdrant-host.example.com
QDRANT_API_KEY=your_qdrant_api_key
REDIS_URL=redis://your-redis-host:6379/0
LLM_API_KEY=your_deepseek_api_key
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key
```

## 3. MySQL 准备

1. 创建独立测试库，例如 `digital_employee_test`
2. 执行 `python app/db/init_db.py` 及 stage3/4/6 表初始化脚本
3. 确认非 root 账号（prod 校验要求，test 建议同样遵守）

## 4. Redis 准备

- 用于沉淀 Session、企微去重 TTL 配置字段
- 验收：`python scripts/prod/check_ai_infra.py --checks redis`

## 5. Qdrant remote 准备

- 使用带 `_test` 后缀的 collection 名
- 验收：`check_ai_infra.py --checks qdrant`

## 6. DeepSeek Key 准备

- 配置 `LLM_API_KEY`，`LLM_PROVIDER=deepseek`
- 验收：RAG 脚本 `check_rag_v2.py`

## 7. LangSmith 项目准备

- `LANGSMITH_TRACING=true`，`LANGSMITH_HIDE_INPUTS/OUTPUTS=true`
- 验收：`check_ai_infra.py --checks langsmith`

## 8. 启动命令

```powershell
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001
```

测试环境若 `APP_ENV=prod`，启动前会通过 `runtime_check` 硬校验。

## 9. 后台访问方式

- API：加请求头 `X-Admin-Token: <测试 Token>`
- 页面：可带 `?admin_token=<测试 Token>` 查询参数

## 10. 回归验收命令

```powershell
python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env" --fast
python scripts/prod/run_all_regression_checks.py --env-file "docs/prod/.env"
python scripts/prod/check_stage6_supplement.py --env-file "docs/prod/.env"
```

## 11. 回滚建议

- 保留部署前数据库备份
- 向量库使用独立 test collection，回滚时可清空 test collection
- 配置回滚：恢复上一版 env 文件（不提交 Git）
