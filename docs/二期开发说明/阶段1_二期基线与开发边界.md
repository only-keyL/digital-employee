# 阶段1：二期基线与开发边界

## 1. 本阶段目标

固定当前 MVP 基线，建立二期开发护栏。本阶段**不开发新业务功能**，只做：

- 统一 Settings 配置类与 dev / test / prod 环境边界
- 启动时运行时配置检查
- 生产配置检查脚本与环境示例文件
- 轻量中文说明文档

## 2. 当前 MVP 基线

| 项 | 说明 |
|---|---|
| Web 框架 | FastAPI，入口 `app/main.py` |
| 健康检查 | `GET /api/health` |
| 本地端口 | 默认 `.env.example` 为 `8001` |
| 问答 | `POST /api/ask`（AskGraph 主流程，本阶段未修改） |
| 知识/未命中/反馈/统计 | 原有 Router 与页面均保留 |
| 企微 | Mock 入口可用，真实回调默认关闭 |
| 配置入口 | `app/core/settings.py`（兼容 `app/config/settings.py`） |

## 3. dev / test / prod 环境区别

| 维度 | dev | test | prod |
|---|---|---|---|
| APP_ENV | dev | test | prod |
| LLM | 允许 mock | 允许 mock | 禁止 mock，必须 Key |
| Qdrant | 允许 local | 通常 local/remote | 必须 remote，禁止 local |
| Redis | 可不配 | 可不配 | 必须 REDIS_URL |
| LangSmith | 可关闭 | 可关闭 | 必须 tracing + Key + Project |
| 企微 | 可关闭 | 可关闭 | 必须启用并配齐密钥 |
| 数据库 | 允许 root | 禁止用生产库名 | 禁止 root |
| 启动策略 | warning 不阻断 | warning 不阻断 | error 阻断启动 |

## 4. 生产启动硬校验规则

`APP_ENV=prod` 时，`app/core/env_validator.py` 会硬校验：

1. 禁止 `LLM_PROVIDER=mock`
2. 禁止 `QDRANT_MODE=local`
3. 必须配置 `QDRANT_URL`、`QDRANT_API_KEY`
4. 必须配置 `REDIS_URL`
5. 必须配置 `LANGSMITH_API_KEY`，且 `LANGSMITH_TRACING=true`
6. 必须配置企微 `CORP_ID / AGENT_ID / SECRET / TOKEN / ENCODING_AES_KEY`，且 `WECOM_ENABLED=true`
7. 数据库账号不能是 root
8. `QDRANT_COLLECTION` 不能带 `_dev` / `_test` 后缀
9. 不允许明显占位符（如 `xxx`、`change_me`、`your_key`）

| 文件 | 作用 |

修改：`app/config/settings.py`（兼容转发）、`app/main.py`（启动检查）、`.env.example`（字段补全）

## 6. 本阶段禁止修改范围

- AskGraph / 问答主流程
- 核心数据库表结构与迁移
- Redis / Qdrant / DeepSeek / LangSmith 真实接入
- 真实企微回调、知识沉淀、审核审计等二期后续能力

## 7. 配置检查命令

```powershell
python scripts/prod/check_prod_config.py --self-test
python scripts/prod/check_prod_config.py --env dev --env-file .env
python scripts/prod/check_prod_config.py --env test --env-file .env.test.example --example-mode
python scripts/prod/check_prod_config.py --env prod --env-file .env.prod.example --example-mode
```

本地启动与 health：

```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8001
curl.exe http://127.0.0.1:8001/api/health
```

## 8. 当前风险和边界

- 本阶段仅**声明并校验** Redis / 远程 Qdrant / DeepSeek / LangSmith / 企微等配置，**未接入客户端**。
- `.env.prod.example` 通过 example 模式只代表字段齐全，**不代表可生产启动**。
- dev 默认仍可使用 MVP 的 mock LLM、本地 Qdrant、root 数据库账号。

## 9. 下一阶段衔接说明

阶段 2 起可按 `docs/prod/开发执行计划.md` 逐步接入 Redis、远程 Qdrant、DeepSeek 等；接入前须先通过 prod 配置检查，且不得跳过本阶段建立的 env 边界。
